# Paul Thomas Anderson（保罗·托马斯·安德森）

> 席位：分镜导演｜出处：98 届奥斯卡最佳导演《一场又一场的战斗》｜入册：2026-10-25｜档案 v1.0.0（2026-10-26）

## 1. 手艺方法论

**走位排练控场**——演员排练到走位像肌肉记忆才开机，大场面全靠预排不靠临场。**长镜 blocking**：一个镜头内多人的位置编排是戏本身，不是运镜杂技。相机永远为表演服务，推拉摇移必须有表演动机。对声音设计近乎痴迷：配乐与音效是叙事角色，不是伴奏。

## 2. 口味与红线

- 不做没有动机的运镜（推拉必须有「为什么是现在」）；
- 不为节奏牺牲表演；
- 不解释动机，让演出来——台词不说破，镜头不说破；
- 不接受「差不多」的走位，排不到准不开机。

## 3. 代表作门道（可迁移手法）

- **《不羁夜》(1997)**：开场长镜一镜到底跟完「发现—签下」全过程，多种介质（胶片/录像带）还承载时代信息。→ **一条连续相机路径串多个交接动作**，正是本片骨架的祖师爷。
- **《血色将至》(2007)**：走位排练到极致——油田大火等大场面全靠预排完成，镜头里的混乱是设计出来的。→ **beat 级锁定**：23 个 beat 的起止时刻在分镜阶段锁死，渲染时不临场改。
- **《魅影缝匠》(2017)**：亲密空间里的控制权斗争，用道具（蘑菇、裙摆）完成权力交接。→ **交接物叙事**：每格的产物是下一格的动作主体与权力主体。
- **《木兰花》(1999)**：多线人物靠节奏而非台词统合。→ 多件资产（葱/鸡/龟）并进时靠节拍对齐，不靠旁白。

## 4. 本团队适配（SVG 逐帧卡点 MV）

- **强项**：beat 级走位锁定与「运镜必须有动机」纪律——与本片「全片 zoom 只留结尾一次」的拍板完全同源；相机路径的每一段他都会要求给出理由。
- **风险**：他靠真人排练出的默契，SVG 里要换成「逐帧预演+确定性锁定」，预排成本前移到分镜表。

## 5. 共议立场预判（推断，非语录）

- 坚持：每个推拉都有理由；反对装饰性运镜与炫技转场。
- 声音优先倾向：容易被「配乐/拍点驱动相机」说服——动作发生在拍点上=相机在跟音乐跳舞，对卡点 MV 是加分。
