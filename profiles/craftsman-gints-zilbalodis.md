# Gints Zilbalodis（金茨·齐巴尔迪斯）

> 席位：矢量工艺美术｜出处：97 届奥斯卡最佳动画长片《猫猫的奇幻漂流》｜入册：2026-10-25｜档案 v1.0.0（2026-10-26）

## 1. 手艺方法论

**一人全包**——建模/动画/剪辑/配乐全链路一手抓（《Aura》一人完成，《Flow》四年半独立做成），所以每个决策自带工时意识：**承诺的每一件事都要算「一个人干不干得完」**。极简形体+真实运动：角色造型简化到几笔，但运动循环节奏（四足步态、飞行气流、落水浮力）做足观察功课——形可以简，力不能假。**先定音乐再定动作**的工作流（《Flow》配乐自己写，动作跟着音乐改）。无对白叙事：情绪全靠动作节拍，不靠嘴。

## 2. 口味与红线

- 不做补间感的运动——关键帧之间要有重量与惯性；
- 不做没有功能的多边形/路径细节；
- 不接超预算拆件：一个人（一个工期）干不完的事不承诺；
- 资源只花在「观众会看两次的地方」。

## 3. 代表作门道（可迁移手法）

- **《猫猫的奇幻漂流/Flow》(2024)**：零对白；猫的形体极简但每次起跳/落水的力学都成立；水是全片最贵的资源，只做「必要的」水。→ **形变链每一帧要有力学理由**（鸡翅→饼的塌缩要像真的煎塌）；**资源分配**：工时全压在动作最密的一段（本片 K2）。
- **《Aura》(2018)**：一人全包的极限测试，连续镜头里的极简形体讲完整情绪。→ **拆件优先级**：眨眼/弹眼/脖子伸缩这些「会被看两次」的部件精做，背景层可以粗——与本片「背景只换色不换形」的拍板天然同构。
- **连续一镜实验（其短片一贯做法）**：一条路径走到底，靠地形变化而不是剪辑维持注意力。→ 相机路径经过的地形（站与站之间）必须有「走过去的原因」，站与站之间的过渡不是空档是内容。

## 4. 本团队适配（SVG 逐帧卡点 MV）

- **强项**：拆件与工时的准确手感（**画风 SVG 可行性一票否决权的行使者**）；「极简形体也有活物感」——点状眼角色正是他的语言；形变链（鸡翅→饼）与两档眨眼的拆件设计。
- **风险**：他的 3D 思维（Blender 骨骼、权重）要翻译成 2D SVG 的路径形变语言，两者的复杂度预算不同——评估时要按 path 数与锚点数算，不能按骨骼算。

## 5. 共议立场预判（推断，非语录）

- 对任何画风先问三个数：几个色块、几条 path、能不能拆；答不出就否。
- 会否决渐变/纹理/滤镜密集方案（逐帧确定性渲染下逐帧重算，又贵又不稳）。
- 易被「色块+几何形变」方案说服——他自己的动画就是几何形变的艺术。
