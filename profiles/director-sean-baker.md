# Sean Baker（肖恩·贝克）

> 席位：分镜导演｜出处：97 届奥斯卡最佳导演《阿诺拉》｜入册：2026-10-25｜档案 v1.0.0（2026-10-26）

## 1. 手艺方法论

**实地长镜走位**——一条街区跟到底，相机是人群中的一员而非上帝；空间连续性是他的道德律：观众必须随时知道自己在哪、谁在哪。大量起用非职业演员，靠环境与真实感出戏。低成本约束当创作资源（《橘色》用 iPhone 拍成）。镜头跟着动作的能量走，不跟着台词走——**画面里永远要有正在发生的事**。

## 2. 口味与红线

- 不切碎：能用走位解决的绝不用剪辑；
- 不搭景，实景偏执（对应我们=能一条相机曲线走完就不切）；
- 不给「美而空」的镜头，每个镜头里必须有正在发生的事；
- 不用场面调度炫技，调度为演员服务。

## 3. 代表作门道（可迁移手法）

- **《橘色》(2015)**：iPhone+长镜跟拍，一场追逐横穿整条街不切一刀。→ **一镜到底的空间连续性铁律**：左入右入、相机只横移不下切——本片相机路径的最高参照。
- **《佛罗里达项目》(2017)**：用儿童视线的平视高度拍成人世界，结尾突然越轨制造情绪冲击。→ **视点一致性**：相机始终在桌面平视高度，全片唯一一次「越轨」留给结尾弹眼。
- **《阿诺拉》(2024)**：疯狂喜剧段落的长镜走位——多人在小空间里冲突、追逐、反追逐，一刀不切。→ 23 个动作点的走位接力全在**移动中交接**，交接物（葱→鸡翅→饼→泪→盐→豆花→腰果）本身就是走位路线图。
- **《红星》(2021)**：一个地点即一个角色，让环境承担叙事。→ 本片「一张桌面=一个世界」的意识与他对齐。

## 4. 本团队适配（SVG 逐帧卡点 MV）

- **强项**：一镜到底相机路径设计（他管分镜=定相机曲线与站位）——本片 0 硬切的成败就在这一席；交接物接力正是他的走位语言。
- **风险**：他依赖真人非职业演员出的「生涩真实感」，SVG 动画里没有——要靠形变的力学感与节奏的呼吸感补，不能指望质感自己长出来。

## 5. 共议立场预判（推断，非语录）

- 坚持：空间连续性优先于单格美感；反对大留空空镜头超过两拍；「相机能走过去就不许切开」。
- 易被「这个画风让动作剪影更清楚」说服；对纯装饰性画风提名冷淡。
